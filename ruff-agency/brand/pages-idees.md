## 1. Système sur mesure
- **Objectif** : vendre l'offre premium vers laquelle pointe le Blueprint.
- **Cible** : les personnes qui ont téléchargé le Blueprint et veulent un résultat unique.
- **Sections** :
  1. Héros : la promesse (des designs uniques, pas « un bon niveau ») et un emplacement vidéo ;
  2. La différence avec le Blueprint gratuit (reprendre les trois niveaux) ;
  3. Ce que fait l'équipe : identité, assets, critères de distinction, affinage, apprentissage de l'IA ;
  4. Le déroulé ;
  5. Exemples réels (emplacements vidéo) ;
  6. Avis en ticker ;
  7. Prix ou « sur devis » ;
  8. FAQ du site ;
  9. Appel final.
- **Manque** : le prix ou le mode de tarification, le délai, ce qui est livré concrètement, un exemple réel de système sur mesure.

## 2. Tarifs
- **Objectif** : rendre le prix lisible et rassurer (garantie, paiement en deux fois).
- **Sections** :
  1. Héros ;
  2. Carte Landing page (1 765 €) et ce qui est inclus ;
  3. Pages supplémentaires et options ;
  4. Comparatif agence / faire soi-même (existant) ;
  5. Garantie « satisfait ou remboursé » ;
  6. Conditions de paiement ;
  7. FAQ prix ;
  8. Appel.
- **Manque** : les prix des autres services (branding, site multi-pages, SEO…), et le délai à retenir (10 ou 14 jours).

## 3. Avant / après
- **Objectif** : prouver par l'image.
- **Sections** :
  1. Héros ;
  2. Filtres (SaaS, agence, PME, indépendant) ;
  3. Paires avant / après, avec les étiquettes du site ;
  4. Une phrase « ce qui a changé » par paire ;
  5. Avis ;
  6. Appel.
- **Données disponibles** : `public/landing-assets/*/before-*.png` et `after-*.png`.
- **Manque** : ton accord pour publier chaque paire.

## 4. Audit de site offert
- **Objectif** : un second lead magnet, pour les visiteurs qui ont déjà un site.
- **Sections** :
  1. Héros avec un formulaire court (URL + email) ;
  2. Ce que contient l'audit ;
  3. Exemple d'audit (capture) ;
  4. Le déroulé (réponse sous 48 h) ;
  5. Avis ;
  6. FAQ ;
  7. Appel.
- **Manque** : le contenu réel d'un audit, et le délai confirmé.

## 5. Notre méthode
- **Sections** :
  1. Héros ;
  2. Étapes ;
  3. Suivi en direct sur WhatsApp ;
  4. Retours et modifications illimitées ;
  5. Outils (Figma, Framer, React) ;
  6. Garantie ;
  7. Paiement ;
  8. FAQ ;
  9. Appel.
- **Manque** : trancher Framer ou React selon l'offre.

## 6. Page SaaS en français
- Traduire et adapter `/saas-redesign`, en gardant la même structure.
- **Manque** : décider si elle est indexée.

## 7. Comparatif des IA (ressource)

  5. Recommandation ;
  6. Appel vers le Blueprint.
- **Manque** : tes résultats de tests.
